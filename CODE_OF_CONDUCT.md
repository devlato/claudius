# Code of conduct

claudius is a project for people who like music and code. Be the collaborator you would want on your own project:
patient with newcomers, direct about problems in the work, and kind about the person who made it.

Not acceptable, in issues, pull requests, discussions or anywhere else the project is represented: harassment,
insults, sexualised language or imagery, personal or political attacks, publishing other people's private
information, and sustained disruption.

Maintainers will remove comments, commits and other contributions that break this, and may ban people from the
project, temporarily or for good, depending on what happened.

To report something, write to the maintainer, [@devlato](https://github.com/devlato), privately (the address is on
the GitHub profile), or use a private security advisory if it is urgent. Reports are read by the maintainers only
and kept confidential.

This follows the spirit of the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
version 2.1, which also describes how enforcement works.
